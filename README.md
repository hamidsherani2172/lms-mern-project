# Learning Management System (LMS) – MERN Stack

## Features
- Role based login (Admin, Instructor, Student)
- Admin can create courses, assign instructors, enroll students, delete courses
- Instructor can view assigned courses and enrolled students
- Student can view enrolled courses

## Technologies
- React.js, Axios
- Node.js, Express.js
- MongoDB, Mongoose

## How to Run

### Backend
cd lms-backend
npm install
npm start

### Frontend
cd lms-frontend
npm install
npm start

Open browser:
http://localhost:3000
